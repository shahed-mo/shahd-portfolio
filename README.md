## Getting Started

Clone the repository:

```bash
git clone https://github.com/shahed-mo/shahd-portfolio.git
```

Navigate to the project:

```bash
cd shahd-portfolio
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

The application will be available locally through the URL shown in your terminal.

## Build

To create a production build:

```bash
npm run build
```
